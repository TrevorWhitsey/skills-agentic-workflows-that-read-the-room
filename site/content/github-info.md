## Recent updates worth watching

- **Copilot code review can approve pull requests.** Copilot now tells you when a pull request is ready to approve, and admins can authorize it to sign off on approval. The ability is off by default. [Source: GitHub Changelog](https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests)
- **Attach media from the GitHub CLI.** A repeatable `--attach` flag uploads a local image or video and references it inline in an issue, pull request, or comment body. [Source: GitHub Changelog](https://github.blog/changelog/2026-09-01-github-cli-media-in-issues-pull-requests-and-comments)
- **Block merges that expose secrets.** Repository rulesets can now block pull requests from merging when they introduce exposed secrets. [Source: GitHub Changelog](https://github.blog/changelog/2026-09-09-block-pull-requests-with-exposed-secrets-from-merging)

## Agentic workflow examples

- **Daily Issues Report.** An agentic workflow that runs on weekdays and files a GitHub issue summarizing new, closed, and stale issues. [Source: Awesome Copilot workflows](https://awesome-copilot.github.com/workflows/)
